# IBEF Engine

A lightweight, high-performance 3D game engine and integrated visual editor developed for optimized desktop performance. Built upon the robust core architecture of Torque 3D, IBEF Engine focuses on speed, low-end hardware efficiency, and seamless in-editor workflows.
